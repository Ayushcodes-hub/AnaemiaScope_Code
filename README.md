# 🩸 AnaemiaScope India
Research prototype for anaemia screening optimized for Indian demographics (Fitzpatrick IV-VI) and ICMR guidelines.

## 🚀 Features
- **Skin Tone Adaptation:** Uses ITA logic for Indian skin types.
- **ICMR Standards:** Hb thresholds aligned with Indian clinical guidelines.
- **ABDM Integration:** JSON output compatible with Ayushman Bharat.
